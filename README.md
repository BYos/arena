# ARENA EAT – MVP

משחק Battle Royale בזמן אמת: אוכלים, גדלים, נשארים אחרונים.

## הרצה מקומית
```bash
npm install
npm start          # http://localhost:3000
```
פותחים את הכתובת בכמה דפדפנים/טלפונים באותה רשת (http://<IP-של-המחשב>:3000) – כולם נכנסים לאותו Lobby.

## מבנה
- `shared/engine.js` – מנוע המשחק ה-authoritative: תנועה, גדילה, אכילה, בונוסים, אזור בטוח, מוות, ניצחון ובוטים. רץ בשרת בלבד במצב אונליין.
- `server.js` – Node + Socket.IO: Matchmaking, חדרים, לולאת 25Hz ושליחת snapshots.
- `public/index.html` – הלקוח (Canvas 2D): Joystick/גרירה/מקלדת/עכבר, HUD, Leaderboard, מסכי מוות/ניצחון, Spectator.
- `tools/build-standalone.js` – בונה `dist/arena-eat-offline.html`: קובץ יחיד לתרגול מול בוטים בלי שרת.

הלקוח שולח רק כיוון ועוצמה (`input {a, t}`); כל ההחלטות על גודל, אכילה, בונוסים, מוות וניצחון מתקבלות בשרת.

## איזון (הכול ב-CONFIG בראש engine.js)
- אכילה רק כשגדול ב-20% לפחות (`EAT_RATIO`), והמנצח מקבל 80% מגודל הנאכל.
- ככל שגדלים – איטיים יותר; מעל 300 יש דעיכה איטית.
- שיחים: מקום מסתור לקטנים, ושחקנים גדולים מ-110 מאטים בתוכם.
- בונוס ⚡ נותן ‎+20 או ‎+10% (הגבוה מביניהם) – יתרון יחסי לקטנים. 💨 מהירות ל-5 שניות.
- אזור בטוח מתכווץ אחרי 50 שניות → משחק של 3–7 דקות.
- 8 שניות חסינות בתחילת המשחק.
- בוטים ממלאים מקומות ריקים (`FILL_WITH_BOTS`), ושחקן שמתנתק מוחלף בבוט.

## מיתוג
שם המשחק: אובייקט `BRAND` בראש הסקריפט ב-`public/index.html`. צבעים: משתני CSS ב-`:root`.

## פריסה
כל שירות Node עם WebSockets (Render, Railway, Fly.io, VPS). `PORT` נקרא ממשתני הסביבה.
